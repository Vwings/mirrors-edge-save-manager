# Built-in Save Asset Notice

The compressed `.dat` resources in this directory are standard Mirror's Edge
PC save files. The completed-campaign and 69% speedrun resources originated as
community-circulated saves whose original authors and download locations are
unknown. The New Game and clean all-Time-Trials-unlocked resources were produced
as controlled local game outputs. The repository maintainer reviewed all four
as ordinary game saves, found no known personal or sensitive information, and
accepted the redistribution risk.

These binary save assets are not claimed to be authored by this project and are
not offered under the repository's GPL-3.0-only license. Mirror's Edge and its
game data are properties of their respective owners. Remove these assets from a
redistribution where local law or platform policy requires clearer permission.

## In-Game Verification

On 2026-08-09, each exact embedded payload listed above was applied through the
manager's guarded activation or Apply path and loaded in the Windows Steam
release of Mirror's Edge. New Game, completed campaign, and 69% speedrun
presented their expected progression states. The all-Time-Trials-unlocked save
presented the completed campaign and unlocked Time Trials without existing PB
or Ghost data. All four loaded without a corruption warning and entered their
available game modes normally.

The uncompressed research samples remain outside version control. The resource
build process must reproduce the listed size and SHA-256 before a compressed
asset is added or replaced.
