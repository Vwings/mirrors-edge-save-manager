# Mirror's Edge Save Manager v0.1.1

Patch release for Simplified Chinese text rendering on English-language
Windows installations.

## Fixed

- Prefer Microsoft YaHei UI for the Simplified Chinese interface so all
  localized glyphs render when Windows would otherwise select an incomplete
  CJK fallback font.
- Preserve Slint's original default font selection for the English interface.

## Troubleshooting

If Chinese characters are still unavailable, install Simplified Chinese
language or supplemental font support in Windows and restart the manager. The
Windows display language can remain English.

## Requirements

- Windows 10 or Windows 11, x64
- Mirror's Edge (2008) for PC
- The game launched at least once so its native save directory exists
