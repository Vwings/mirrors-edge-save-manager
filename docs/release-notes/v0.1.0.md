# Mirror's Edge Save Manager v0.1.0

Initial Windows release of the unofficial save manager for Mirror's Edge
(2008).

## Highlights

- Discover the Windows account-named Current save through the Documents known
  folder.
- Capture Current as reusable Presets or history Stashes.
- Import external `.dat` files without adding duplicate verified Preset content.
- Avoid redundant captures when an identical verified save already preserves
  Current, and prevent applying content that already equals Current.
- Track the last Apply source and whether Current changed afterward.
- Organize built-in Presets separately from user Presets and clear Stash history
  after explicit confirmation.
- Apply any Preset or Stash after automatically preserving Current when needed.
- Recover interrupted replacements through verified journals and rollback data.
- Include four verified, read-only built-in Presets.
- Provide English and Simplified Chinese interfaces.

## Safety

Close Mirror's Edge before changing saves. The manager blocks mutations while
`MirrorsEdge.exe` runs, verifies complete save fingerprints, and preserves the
previous Current until replacement verification succeeds. Keep normal system or
cloud backups for important profiles.

## Requirements

- Windows 10 or Windows 11, x64
- Mirror's Edge (2008) for PC
- The game launched at least once so its native save directory exists
